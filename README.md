# BlockBlastLite

Кроссплатформенная логическая игра-головоломка с механикой размещения фигур на сетке, разработанная на языке C# с использованием фреймворка .NET MAUI. Проект представляет собой легковесную, оптимизированную альтернативу популярным мобильным головоломкам, полностью свободную от рекламных трекеров, фоновых сетевых запросов и избыточного потребления ресурсов.

## Техническая концепция

Основная цель разработки — создание отзывчивого игрового цикла (Game Loop) и точной обработки жестов перетаскивания (Drag-and-Drop / Pan Gesture) средствами нативного UI-фреймворка без использования тяжеловесных сторонних игровых движков.

## Ключевые особенности реализации

* **Оптимизированная логика игрового поля:** Представление игровой сетки в виде двумерной структуры данных с проверкой коллизий, валидацией доступных ходов и расчетом заполненных линий за минимальное время (O(N) для проверки строк и столбцов).
* **Процедурная генерация фигур:** Сбалансированный алгоритм формирования пула следующих блоков с проверкой проходимости и динамическим расчетом очков за комбо-очистки.
* **Отсутствие телеметрии и рекламы:** Приложение работает полностью автономно (Offline-first), не требует сетевых разрешений и минимизирует нагрузку на аккумулятор и оперативную память устройства.
* **Низкая задержка ввода:** Плавная обработка касаний и перетаскивания объектов с визуальным предпросмотром позиции размещения фигуры на сетке.
* **Локальная персистентность:** Автоматическое сохранение текущего прогресса партии и таблицы рекордов в локальном хранилище устройства.

## Технологический стек

* **Язык программирования:** C# (.NET)
* **Фреймворк:** .NET MAUI (Multi-platform App UI)
* **Графика и UI:** XAML / MAUI Graphics, кастомные контролы и анимации переходов
* **Архитектура:** MVVM (Model-View-ViewModel), разделение математической модели поля и слоя отрисовки
* **Целевые платформы:** Android, Windows

## Структура проекта

```text
BlockBlastLite/
├── Models/                # Математическая модель сетки, матрицы фигур и состояния игры
├── ViewModels/            # Управление игровым циклом, подсчет очков и обработка команд
├── Views/                 # XAML-разметка экранов, игрового поля и визуальных компонентов
├── Services/              # Генератор фигур, сервис сохранения состояния и рекордов
├── Resources/             # Шрифты, цветовые словари, иконки и стили приложения
├── MauiProgram.cs         # Точка входа и регистрация сервисов
└── README.md              # Документация проекта
```

## Сборка и запуск

### Предварительные требования
* .NET SDK с установленным компонентом `maui` (`dotnet workload install maui`)
* Android SDK (для сборки под ОС Android) или Windows SDK (для сборки под ОС Windows)

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DeAdmin01/BlockBlastLite.git
   cd BlockBlastLite
   ```

2. Восстановите зависимости проекта:
   ```bash
   dotnet restore
   ```

3. Соберите релизный APK/AAB-пакет для Android:
   ```bash
   dotnet publish -f net9.0-android -c Release
   ```
